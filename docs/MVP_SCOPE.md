# MVP Scope

## User
CMPDI/Ministry reporting or technical officer handling a high-priority information request.

## Benchmark
Subsidiary-wise underground/opencast coal production by quality across selected financial years.

## Core promise
Retrieve evidence, understand its context, detect meaningful discrepancies, preserve provenance, and produce a human-reviewable report.

## Explicit non-goals
- replacing Koyla Shakti
- replacing CIL/CMPDI document management
- building a new OCR engine
- generic chatbot
- generic dashboard
- autonomous official submission
